# ClassLoop 最终验收包

这套材料对应三位助教的独立验收站点。现场先从仓库根目录运行：

```powershell
.\start_classloop.ps1 -Mode Full
```

然后打开 `http://127.0.0.1:5173/acceptance`。页面顶部的 01、02、03 分别对应助教1、助教2、助教3。

## 最短演示顺序

1. 助教1：打开 01，按“定位 → 迭代 → 方案差异 → F/I/H/S边界 → 风险”讲 5—6 分钟。
2. 助教2：打开 02，先展示 V1→V2 表，再由助教随机选择 F1/F2/F3 并运行；展示角色、状态、run_id、原始日志。
3. 助教3：打开 03，根据对方抽查内容复制路径，在 VS Code 中用 `Ctrl+P` 粘贴定位。

## 关键文件

- `EVIDENCE_INDEX.md`：最终证据索引。
- `TA1_PROJECT_DECK.md`：助教1的7页独立展示稿。
- `TA2_AGENT_DECK.md`：助教2的7页独立展示稿。
- `V1_TO_V2_CASE.md`：真实 V1 问题到 V2 修复的闭环。
- `HUMAN_AI_BOUNDARY.md`：Agent、规则程序、人工及其他工具的边界。
- `TEST_REPORT.md`：最终回归测试结果。
- `VERSION.json`：版本、角色、Prompt和入口清单。

## 现场异常处理

- 页面显示“真实模型完成”：说明 VentureAgent 模型请求成功且输出通过 V2 协议检查。
- 页面显示“明确降级”：说明模型不可用或输出不满足协议，系统使用规则兜底；错误原因与兜底结果会一起保存，不能称为真实模型输出。
- 页面提示 503：说明 VentureAgent 服务未启动或地址未配置。重新用 `-Mode Full` 启动，不要把失败说成成功。
